# Titanic Survival Prediction API

[![Titanic API CI](https://github.com/patrickfelder777-cpu/titanic-survival-prediction-api/actions/workflows/ci.yml/badge.svg)](https://github.com/patrickfelder777-cpu/titanic-survival-prediction-api/actions/workflows/ci.yml)

An end-to-end machine learning application that predicts Titanic passenger survival using a **Random Forest classifier**, a **FastAPI REST API**, automated integration tests, and **GitHub Actions CI**.

Built as a portfolio project demonstrating Python backend development, machine learning integration, reproducible preprocessing, API validation, and automated testing.

## Tech Stack

- **Language:** Python 3.11
- **Machine Learning:** scikit-learn, pandas, NumPy
- **Backend:** FastAPI, Pydantic, Uvicorn
- **Testing:** pytest, HTTPX
- **CI/CD:** GitHub Actions
- **Containerization:** Docker configurations for training and serving
- **Model Serialization:** joblib

## Architecture

The application uses a saved scikit-learn Pipeline containing:

1. Feature engineering for `FamilySize` and `IsAlone`.
2. Numeric median imputation.
3. Categorical mode imputation.
4. One-hot encoding.
5. Random Forest classification.

The dataset is split into training and testing sets before preprocessing is fitted, preventing training-data leakage into the held-out evaluation.

The FastAPI application loads the same trained pipeline used during evaluation, avoiding differences between training and serving preprocessing.

This revised implementation replaces the original coursework preprocessing, which included inconsistent feature transformations.

## Model Performance

The corrected Random Forest pipeline was trained using the Kaggle Titanic training dataset containing 891 passenger records.

An 80/20 stratified split produced a held-out test set of 179 passengers.

| Metric | Result |
|---|---|
| Accuracy | **81.56%** |
| F1 Score | **0.736** |
| ROC-AUC | **0.835** |
| Test Samples | 179 |

### Confusion Matrix

| | Predicted Not Survived | Predicted Survived |
|---|---:|---:|
| Actual Not Survived | 100 | 10 |
| Actual Survived | 23 | 46 |

These results describe the held-out test split, not performance on a separate external validation dataset.

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/` | Application status |
| GET | `/health` | Model readiness |
| GET | `/model-info` | Saved model evaluation metadata |
| POST | `/predict` | Single passenger prediction |
| POST | `/predict-batch` | Predictions for 1–1,000 passengers |

The API validates passenger class, sex, embarkation port, passenger counts, fare, and age.

### Example Prediction Request

```json
{
  "Pclass": 1,
  "Sex": "female",
  "Age": 28,
  "SibSp": 0,
  "Parch": 0,
  "Fare": 100.0,
  "Embarked": "S"
}
```

### Example Prediction Response

```json
{
  "survived": 1,
  "survival_probability": 0.982907029478458
}
```

This example was generated by the locally trained model. Predicted probabilities are not calibrated confidence estimates.

## Local Installation

Use Python 3.11.

Clone the repository:

```bash
git clone https://github.com/patrickfelder777-cpu/titanic-survival-prediction-api.git
cd titanic-survival-prediction-api
```

Create and activate a virtual environment:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

Download the Titanic training dataset from [Kaggle](https://www.kaggle.com/competitions/titanic/data) and save `train.csv` as `data/titanic.csv`.

The dataset is excluded from the repository.

Train the model:

```bash
python -m training.train_model --data data/titanic.csv
```

Start the API:

```bash
python -m uvicorn serving.app:app --reload
```

Open the interactive API documentation:

**http://127.0.0.1:8000/docs**

Training creates the model artifacts under `models/`. Only load trusted joblib files.

## Automated Testing

Four API integration tests were added using pytest and FastAPI's TestClient.

The tests cover:

- API health and readiness.
- Single passenger predictions.
- Batch predictions.
- Invalid input rejection.

Run tests locally after training:

```bash
python -m pytest tests/test_api.py -v
```

**Local result: 4 tests passed.**

## Continuous Integration

GitHub Actions automatically runs the CI workflow on pushes and pull requests.

The workflow:

1. Checks out the repository.
2. Configures Python 3.11.
3. Installs project dependencies and testing libraries.
4. Downloads a publicly hosted Titanic dataset.
5. Trains the model.
6. Runs the automated API tests.

**GitHub Actions status: Passed**, verified on October 18, 2026.

The CI dataset source differs from the Kaggle download used for the locally reported evaluation metrics.

## Project Improvements

This portfolio revision addresses several limitations of the original coursework implementation:

- Reduced preprocessing leakage by splitting before fitting transformations.
- Unified training and inference preprocessing.
- Added model artifact and metadata persistence.
- Added input validation and batch prediction support.
- Added automated API integration tests.
- Implemented GitHub Actions continuous integration.
- Verified model performance on a held-out test set.

The historical implementation is retained separately for provenance.

## Limitations

This is a portfolio demonstration rather than a production-hosted service.

Further production improvements could include authentication, rate limiting, monitoring, model versioning, automated deployment, and additional validation.

The model's predictions are educational estimates based on historical passenger data.
